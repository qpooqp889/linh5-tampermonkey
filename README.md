# LinH5 工具箱 - Tampermonkey Userscript

> **目前版本：v3.0.46（2.0 擴充版）**

一個專為 [LinH5 放置天堂 · 即時版](https://linh5web.win/) 設計的 Tampermonkey 增強腳本。

## 📦 安裝

### 前置需求
1. 瀏覽器安裝 [Tampermonkey](https://www.tampermonkey.net/) 擴充功能
2. 點擊下方安裝連結

### 安裝連結
> [**🔗 安裝 LinH5 工具箱 v3.0.3**](https://raw.githubusercontent.com/qpooqp889/linh5-tampermonkey/main/linh5-tampermonkey.user.js)

或手動新增腳本，將 [linh5-tampermonkey.user.js](./linh5-tampermonkey.user.js) 內容貼入。

## ✨ 功能

### 🚀 2.0 擴充功能

v3.0.46 在既有功能之外加入一組低耦合的工具層。開啟右上角設定面板後，可以使用「匯出設定」將 `lh5_` 開頭的 localStorage 設定與 Tampermonkey 設定保存為 JSON；使用「匯入設定」可在重新安裝瀏覽器或更換裝置後恢復設定。匯入時只接受本工具產生的資料格式，且只寫入 `lh5_` 前綴的鍵值，不會覆蓋其他網站資料。

「狀態面板」會顯示目前地圖、HP、MP 與掛機狀態；在遊戲頁面也可以使用 `Ctrl+Shift+L` 快速開關。面板只在開啟時更新資料，避免增加不必要的頁面負擔。userscript metadata 同時加入 `@updateURL` 與 `@downloadURL`，方便 Tampermonkey 自動檢查更新。

「🛡️ 批次安定值」會從目前的背包 DOM 只掃描 `.subtab[data-c="wpn"]` 武器分頁與 `.subtab[data-c="arm"]` 防具分頁，並以該分頁內的 `.cell[data-i]` 作為實際背包 index；`.cnt` 作為持有數量。資料會依分頁、道具名稱與強化值分組，以下拉選單顯示。輸入批次數量後，程式會先切換到該道具所屬分頁，再依序送出封包；一般強化與安定值強化共用封包間隔，預設每 500ms 一次，可在介面調整。模式選擇「安定值強化」時送出 `enhanceSafeInv(index)`；選擇「一般強化」時送出 `enhanceInv(index)`。批次強化支援武器／防具分頁、下拉選取、重新掃描最新 `data-i`；掃描時會排除含有 `.lockbadge`（🔒）的鎖定 index，不會列入下拉、MAX 數量或實際強化；停止強化值改為 +1～+12 下拉選單；武器預設 +7、防具預設 +5，選取值會依武器／防具分類保存到 localStorage，達到停止值後不再強化。一般強化按鈕會在同一個批次強化 Modal 內切換成確認摘要，必須在同一個 Modal 再按「確認開始強化」才會切換分頁並送出封包；按「返回修改」或關閉不會執行；強化失敗導致數量下降時允許下一件補位後繼續尋找，完全找不到剩餘目標或結果逾時才停止。診斷訊息會以 `[LH5][LOCK-DEBUG]` 開頭，包含 `START`、`FOUND`、`EMIT`、`CHECK`、`SUCCESS`、`MISSING` 與 `TIMEOUT` 標籤，方便測試時從 Console 複製完整紀錄。封包間隔可由介面調整（預設 500ms），一般強化與安定值強化共用此頻率，避免連續送出過快。設定面板的「📊 強化記錄」可查看最多 500 筆歷史；成功率以已判定的成功／失敗筆數計算，若遊戲未回傳可判定的背包變化則標示為「未知」。面板提供「匯出 CSV」，會下載 `linh5-enhance-log-YYYY-MM-DD.csv`，並加入 UTF-8 BOM 以支援 Excel 正確開啟中文；記錄表與 CSV 已移除「目前強化值」欄位。批次強化下拉選項與停止值下方的實際 index 提示最多顯示前 5 個，超過部分會以「另 N 個」表示；批次強化介面新增封包間隔輸入欄，預設 500ms，一般強化與安定強化共用此頻率，並保存至 localStorage；批次強化數量欄位提供清空 X 與 MAX 按鈕，MAX 會填入目前選取裝備的最大可強化數量；批次強化 Modal 的參數區可獨立捲動，底部「取消／開始強化」操作列固定在下方；批次強化裝備下拉選單上方提供關鍵字搜尋，可依道具名稱、武器／防具分類或強化等級即時篩選；關鍵字會保存至 localStorage，重新開啟 Modal 時自動恢復並套用，清空關鍵字即可恢復全部選項。選擇批次強化下拉裝備後，會依該選項更新數量欄位上限與 MAX 可用值；不會持續重建下拉選項。批次強化開始後會保留同一個 Modal，右上角 X 只隱藏進度視窗、不會中斷批次；一般強化每一輪都重新掃描下拉選取的分類、名稱與強化值分組；例如選擇 `+6` 只搜尋 `+6`，不會改強化 `+0` 或追蹤已變成 `+7` 的物品；若 index 前移則使用最新 data-i；進度畫面提供「取消」並恢復初始化設定；批次完成後按「關閉」也會恢復初始化設定；顯示 `1/20` 進度、成功／失敗／未知數量、進度條與最近結果。成功以綠色顯示；失敗會顯示「強化消失」、「道具已破壞」或「維持不變」；結果優先讀取頁面 `#toast` 的「獲得狀態：道具名稱 +N」與「強化失敗，道具已破壞！」訊息；`+N` 會寫入強化後等級並歸類為成功，破壞訊息歸類為失敗，兩者都會寫入歷史清單；若 toast 顯示缺少「對盔甲施法的卷軸」或「對武器施法的卷軸」，會保留原始提示寫入 Log，並停止目前批次；強化批次進度存在期間收到的 socket 返回事件會記錄事件名稱、來源與 payload，避免結果先被 toast 判定後漏記，於「📊 強化記錄」面板查看，最多保留 200 筆、面板顯示最新 50 筆。

### ⚙ 設定面板
Topbar 右側 ⚙ 齒輪按鈕 → 開啟設定 Modal，可用開關切換功能。
> Modal 支援捲動（max-height: 90vh），設定項目太多也不卡版面。

### 🐉 世界王自動更新置頂
- 「存活中」的世界王自動排到列表最前面
- 已被擊敗的王恢復原始順序
- ★ 星星可**置頂最愛王**（儲存於 localStorage），不受死活影響
- Top 狀態列顯示最近重生王的倒數計時
- 每秒更新

### 🎒 背包物品檢索
- 搜尋框：依道具**名稱**過濾格子
- 下拉選單：依**強化值 +4 ~ +10** 篩選
- 統計顯示「顯示 X / 總數」

### 💰 交易所金錢搜尋
- 名稱搜尋框下方新增 `💰` 金額輸入框
- 模糊數字匹配：輸入 `800` 可找到 `2,800,000`
- 右側排序下拉：可選「價錢低→高」排序
- *v2.94: 移除價格簡寫功能（網站已內建），修正排序邏輯兼容新版 DOM*

### 🏷️ 變更姓名
- 開關「變更姓名」，開啟後顯示輸入框
- 輸入自訂名稱按套用（或 Enter），立即修改 topbar 顯示名稱
- 名稱儲存於 `localStorage`，每 600ms 自動防覆蓋
- 純前端顯示，不影響伺服器資料

### 🤖 自動掛機腳本（MP管理）
- **設定路徑**：⚙ 設定 → 開啟「自動掛機腳本」
- **MP 管理**：MP 低於門檻 → 回大廳休息；MP 高於門檻 → 出發到指定地圖攻擊
- **地圖分類**：自動辨識野外/地監，切換對應 subtab
- **🔍 地圖過濾**：下拉上方有搜尋框可即時過濾地圖
- **運行/停止按鈕**：手動點擊才開始（🟢 ▶ 運行 / 🔴 ■ 停止）
- **齒輪動畫**：運行中 ⚙ 外框會有綠色旋轉邊框
- **斷線重連**：
  - 選擇角色位置（0 / 1 / 2）
  - 自訂檢查間隔（預設 300 秒）
  - 自動流程：`btn-login → 等 5 秒 → 選角色 → 等 5 秒 → goToZone`

### 😍 好友系統
- Topbar 名稱右側 😍 按鈕 → 開啟好友管理
- **新增**：輸入玩家名稱按新增，存於 `localStorage`
- **搜尋**：即時過濾好友列表
- **刪除**：每項獨立刪除按鈕
- **匯出 JSON**：下載 `好友清單_YYYYMMDD.json`
- **匯入 JSON**：選取檔案自動合併（名稱不重複）

### 🎬 戰鬥畫面縮放
- 設定開關「戰鬥畫面縮放」
- 隱藏時刪除怪物/戰鬥資訊，只保留自訂的血條與 MP 條
- 不隱藏時恢復原始介面

## 🔧 技術細節

- **純 Tampermonkey** — 無外部依賴，`GM_setValue/getValue` 存設定
- **超級巡邏員** — 單一 `setInterval` 監聽 SPA 頁面重建，自動重掛所有功能
- **星星置頂** — 使用 `localStorage` 持久化最愛王列表
- **好友清單** — 使用 `localStorage` 儲存 `[{name, addedAt}]` JSON 陣列
- **掛機設定** — 使用 `localStorage` 儲存 MP 門檻、目標地圖、斷線參數
